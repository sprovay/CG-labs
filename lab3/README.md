# Лабораторная работа №3 — текстурирование

Вариант 4: три усечённых правильных тетраэдра. Сохранены камера, проекции,
преобразования, анимация, материалы и настраиваемое освещение из лабораторной №2.

## Реализовано

- Текстурные координаты создаются отдельно для каждой треугольной и
  шестиугольной грани модели.
- PNG-файлы загружаются с диска через `stb_image`; изображения создаются в
  памяти GPU через staging buffer. Вершинные и индексные буферы всех моделей
  также копируются в память GPU.
- Для каждого из трёх материалов выделен отдельный набор дескрипторов с
  albedo, specular и emissive картами. Материал каждого объекта выбирается в
  ImGui. Если дополнительной карты нет, используется чёрная текстура 1×1.
- Один динамический uniform-буфер содержит свойства всех трёх моделей.
  Смещение передаётся при привязке набора дескрипторов.
- Первый объект поддерживает включаемое анимированное сэмплирование той же
  albedo-карты по вторым, изменяющимся со временем координатам. Результат
  смешивается и модулируется; параметры эффекта передаются через
  push-константы.
- Specular-карта управляет силой блика, emissive-карта добавляет свечение
  независимо от модели освещения Блинна—Фонга.
- Переключатель `Lab 2 vertex colors` возвращает процедурную окраску
  предыдущей лабораторной работы для сравнения.

## Сборка и запуск

Нужны CMake, Ninja, компилятор C++20, Vulkan SDK с `glslc` и доступ к
зависимостям CMake (`glfw`, `vk-bootstrap`, Vulkan Memory Allocator, ImGui).
Из папки `lab3` выполните:

```bash
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/cg-lab3
```

Запускайте программу из `lab3`: пути к шейдерам и PNG-файлам относительные.
`stb_image.h` включён в репозиторий; Python и Pillow нужны только для
повторной генерации демонстрационных текстур командой
`python3 tools/generate_textures.py`.

## Управление

В окне ImGui можно выбрать материал для каждой модели и менять параметры
камеры, движения и освещения. Параметры анимированной текстуры находятся в
разделе `Models and materials`. Материал Basalt демонстрирует отсутствие
specular и emissive карт и использование чёрной служебной текстуры.
