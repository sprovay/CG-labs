# Лабораторная работа №2 — камера и освещение

Вариант 4: усечённый правильный тетраэдр из лабораторной работы №1.

## Реализовано

- управляемая камера: позиция, yaw, pitch и угол обзора;
- сохранённые возможности лабораторной №1: перспективная и
  ортографическая проекции, общая трансформация, цветовой оттенок и
  анимация по траектории Лиссажу;
- процедурные плоские нормали граней;
- процедурная окраска вершин по локальным координатам, совмещённая с
  материалом и освещением;
- модель освещения Блинна—Фонга во фрагментном шейдере;
- настраиваемые ambient light, направленный свет и материалы моделей;
- отдельные наборы дескрипторов сцены (`set 0`) и модели (`set 1`);
- динамические массивы точечных источников и прожекторов в storage buffers;
- затухание точечного и прожекторного света по закону обратных квадратов;
- мягкие края прожектора с внутренним и внешним углами;
- добавление, удаление и настройка источников через ImGui;
- визуализация источников кубами и конуса прожектора линиями;
- три экземпляра модели с независимыми материалами и преобразованиями.

## Сборка и запуск

```bash
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/cg-lab2
```

Программу нужно запускать из папки `lab2`, так как SPIR-V шейдеры загружаются по относительным путям.

Все параметры камеры, материалов и освещения находятся в окне ImGui. Разделы можно раскрывать и сворачивать. Флажок `Show light visualizers` включает кубы источников и контуры прожекторных конусов.
