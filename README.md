# Лабораторная работа №1 — Vulkan

Вариант 4: усечённый правильный тетраэдр.

## Реализовано

- построение и индексированная отрисовка модели;
- перспективная и ортографическая проекции;
- управление положением, вращением и масштабом через ImGui;
- движение и вращение по настраиваемой траектории Лиссажу;
- запуск, пауза и изменение скорости анимации;
- выбор общего цвета объекта;
- процедурная окраска вершин по локальным координатам;
- три объекта с отдельными uniform buffers и `VkDescriptorSet`.

## Сборка и запуск

```bash
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

Программу необходимо запускать из корня проекта, поскольку шейдеры загружаются по относительным путям.

## Управление

Все параметры находятся в окне ImGui: выбор проекции, преобразования объектов, параметры анимации и общий цвет.
