# Лабораторные работы по компьютерной графике

Репозиторий содержит лабораторные работы по компьютерной графике на C++ и Vulkan.

## Проекты

- [`lab1`](lab1/) — усечённый правильный тетраэдр, графический pipeline, преобразования, анимация и descriptor sets.
- [`lab2`](lab2/) — развитие сцены из первой работы: камера, материалы,
  освещение Блинна—Фонга и динамические источники света.
- [`lab3`](lab3/) — текстуры albedo, specular и emissive, выбор материалов,
  анимированное сэмплирование и геометрия в памяти GPU.

Инструкции по сборке и запуску находятся в README соответствующей лабораторной работы.
